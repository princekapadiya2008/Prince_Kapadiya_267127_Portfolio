# Suggested GitHub commit sequence

The Web Technology guidelines ask for at least five meaningful commits. Make commits as you add or improve parts of the project; do not create empty or backdated commits just to reach the count.

Suggested sequence when setting up the repository:

1. `Add portfolio HTML structure` — add `index.html`.
2. `Add portfolio styling and responsive layout` — add `css/style.css`.
3. `Add JavaScript interactions` — add `js/script.js`.
4. `Add profile photo and website screenshot` — add `images/prince.jpg` and `screenshots/portfolio-desktop.png`.
5. `Write project README` — add `README.md`.

If the files are already uploaded together, make genuine later improvements in separate commits instead, such as correcting project links, updating the contact email, improving mobile spacing, or adding project screenshots. Do not make commits that do not represent real changes.
